Architecture

Run it where your code belongs.

A writable Trace node hosts ordinary bare Git repositories on your machine or VPS. An optional read-only mirror keeps another copy available for cloning and recovery.

✓Your existing Git client works with Trace.
✓Control access with users, teams, and repository roles.
✓Inspect signed peer identity before trusting a replacement.

Replication model

Writable nodePush · review · merge
PRIMARY
Read-only mirrorSigned sync · clone · recover
REPLICA

Mirror sync is configured and checked by an operator. It is not automatic multi-writer federation.
